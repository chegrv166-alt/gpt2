# Вельский уезд 0.8.0 — локальная проверка

Состояние: исходный код, исправления и локальные архивы проверены. Удалённая публикация не выполнялась.

## Что входит

Единая карта 512×384. 25 именных мест и 5 лагерей составляют 30 именных точек; отдельно 16 находок. Пять районов связаны дорожными кольцами и тремя реальными мостами. Карьер и вода непроходимы. 1114 записей декораций индексируются по секторам 32×32; при отрисовке выбирается видимая область с запасом для высоких изображений.

Четыре добавленных столкновения имеют местные последствия. Существующие gate/rescue/ritual остаются совместимыми. Находки и награды ограничены одноразовыми флагами. Открытие мест, посещённые сектора и лагеря сохраняются. Снимок версии 1 переносится к новому старту вместе с вложенной контрольной точкой, сохраняя решения, здоровье, голоса и активный бой.

## Воспроизводимые проверки

```sh
bash godot/tools/check.sh
bash godot/tools/export.sh
```

Godot 4.6.3. В этой среде XDG_DATA_HOME=/workspace/godot-user/data, XDG_CONFIG_HOME=/workspace/godot-user/config, XDG_CACHE_HOME=/workspace/godot-user/cache. Графические захваты выполнены через Xvfb и Mesa/OpenGL; headless-проверка сама по себе не доказывает отрисовку.

Итоговый прогон: **430 проверок, 0 ошибок** (74 модель, 102 арт, 103 география, 41 исследование, 21 сцена, 34 визуальная геометрия, 17 региональная сцена, 38 законное прохождение). Полные логи: `/tmp/county-final-check` в рабочей среде.

Независимое ревью всей ветки нашло три существенных ошибки загрузки. Все исправлены с RED→GREEN регрессиями: камера после загрузки далёкого сохранения; слишком большие координаты до преобразования в Vector2i, включая вложенную контрольную точку; неверные типы данных до замены кампании, включая загрузку настоящего JSON-файла. Полный прогон после исправлений зелёный. Существующее прохождение также сохраняет и загружает все три финала.

Отложенная мелочь ревью: длинный сегмент дороги может исчезнуть с локальной миникарты, если один конец выходит за её рамку. Полная карта по M показывает все дороги.

География проверяет реальную AStar-достижимость всех 46 входов и проходимость мостов. Региональная сцена выполняет полный маршрут от города до архива по клеткам; не подменяет его телепортом. Прохождение легально достигает целей всех семи боёв. Миграция использует сохранённый JSON настоящей кампании версии 1, включая обращение и контрольную точку.

Все 10 исходных PNG проверены по SHA256, размерам и режиму из godot/assets/painted/sources.json. Новые изображения сохранены без изменения исходных байтов; точные запросы и происхождение прилагаются.

## Платформы и ограничения

Обе сборки используют официальные release templates Godot 4.6.3 и встроенный PCK. Linux — ELF x86-64, Windows — PE32+ x86-64. Встроенный Windows-пакет отдельно загружен Linux-редактором: версия 0.8.0, 46 мест, карта 512×384 и новые изображения присутствуют. Это проверка ресурсов, а не запуск Windows-программы на Windows.

Экспортированный Linux-файл запускается из /tmp вне проекта, сообщает CHRONICLE_READY и отрисовывает мир/бой с настоящим OpenGL-контекстом. Windows GUI в этой Linux-среде не проверен. GitHub Actions способен проверять запуск на целевых ОС при последующей авторизованной публикации; этот локальный прогон его не заменяет.

Полноценная направленная покадровая анимация, озвучка, найм и новые акты не входят в расширение карты. Длительность и баланс нуждаются в живом плейтесте. Числа FPS без замера не заявляются.

## Решения по проверке

Ревьюер оставил окончательные архивы и Windows GUI за рамками своего снимка. Архивы проверены исполнителем после экспорта; для Windows сохраняется явное ограничение проверки, поскольку доступна Linux-среда. Возможная цена этого решения — специфичный для Windows сбой запуска или графики, который можно обнаружить только запуском на Windows.
