# Шаг 4: завершение вертикального среза

Пользователь подтвердил реализацию следующего этапа исходной спецификации. Цель — замкнуть цикл «бой → лут → экипировка → усиление → мини-босс» в существующей браузерной ARPG.

## Контракты

- TypeScript strict, Phaser 3.90.0, Vite; без новых зависимостей, внешних URL и бинарных ассетов. Новые текстуры сфер генерируются Graphics.generateTexture в BootScene.
- ItemInstance: уникальный id, русское имя, slot weapon/armor, rarity common/rare/legendary, неизменяемые модификаторы StatsComponent.
- InventoryComponent: ровно 10 слотов; add отказывает без изменения при переполнении/дубликате; equip атомарно меняет предмет с текущим снаряжением; unequip требует свободный слот. Модификаторы не накапливаются от повторного надевания и не лечат.
- LootSystem создаёт DropItem по каждому уникальному событию смерти противника. Босс гарантирует Legendary. Подбор по клику с автосближением или в радиусе 0.85 клетки с прямой видимостью. При полном рюкзаке предмет остаётся на земле. Лучи и надписи используют цвета редкости. Выброшенный предмет размещается в свободном месте вне радиуса автоподбора.
- AdventureSystem объединяет прогресс, инвентарь и лут, не зависит от Phaser. Исход playing/dead/victory; смерть имеет приоритет. Победа показывается один раз за встречу. Можно продолжить исследование и забрать награду.
- Респавн возвращает героя ко входу, восстанавливает ресурсы и встречу, сохраняет инвентарь/экипировку и убирает старый наземный лут. R/новый поход очищает весь прогресс.
- Отдельная UIScene: сферы HP/маны, хотбар, окно рюкзака/снаряжения/статов, экраны конца. Интерфейс не зависит от масштаба мира. Модальные окна блокируют ввод в мир и останавливают симуляцию. I/кнопка открывает инвентарь, Esc закрывает его. Респавн/продолжение доступны кнопками и Enter.
- Существующий DOM-каркас сохраняет доступные команды и статусы; дублирование логики ресурсов не допускается. На 390 px нет горизонтального переполнения.

## Проверка

Чистые тесты: атомарная замена при полном рюкзаке, отказ снятия без места, ограничение ресурсов при снятии, отсутствие дублирования лута, стены/мертвый герой/переполнение при подборе, легендарный дроп босса, победа и смерть, сохранение экипировки при респавне. Браузер: реальное убийство/подбор/экипировка, модальная пауза и изоляция ввода, изменение сфер, смерть/респавн, победа/продолжение, мобильный экран и повторный запуск. Затем весь набор тестов, strict build, production WebGL/Canvas, отсутствие внешних запросов.
